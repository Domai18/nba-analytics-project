# NBA Performance Analytics Project

## Overview
This project explores patterns in NBA player and team performance using statistical analysis and predictive modeling. The goal was to understand how shooting behavior and efficiency metrics relate to outcomes over time.

## Data
The analysis uses publicly available NBA datasets. No proprietary or confidential data was used.

## Methods
- Exploratory data analysis (EDA)
- Feature engineering
- Regression and/or classification models
- Model evaluation and interpretation

Tools used include R studio and data visualization libraries.

## Results
The models reveal relationships between shot selection, efficiency, and performance outcomes. Emphasis was placed on interpretability rather than optimization alone.

## Key Takeaways
- Demonstrated ability to clean and analyze real-world datasets
- Applied statistical reasoning to sports analytics
- Built reproducible analytical workflows

## Reproducibility
Notebooks can be run sequentially to reproduce results.
